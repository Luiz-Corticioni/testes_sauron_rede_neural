# Registro da licença — 21/11/2026

O responsável escolheu Apache License 2.0 para o código próprio do Sauron. O
texto oficial foi incluído em `LICENSE`; README, índice e documento de decisão
foram atualizados para explicar o escopo e os materiais de terceiros.

## Verificação

- O SHA-256 do arquivo local `LICENSE` foi comparado com uma segunda obtenção de
  `https://www.apache.org/licenses/LICENSE-2.0.txt`: os arquivos coincidem.
- Os quatro arquivos de licença dos componentes D3 presentes no repositório
  foram encontrados e preservados. `git diff --check` não indicou erros.
- Não foram executados testes da aplicação: esta etapa alterou apenas licença e
  documentação. A titularidade integral, as regras institucionais e as licenças
  de todos os componentes transitivos e materiais distribuídos não foram
  verificadas; consulte [a decisão](DECISAO_LICENCA.md).
