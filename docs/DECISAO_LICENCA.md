# Decisão pendente: licença do Sauron

**Estado: não decidida.** A publicação do código em um repositório não escolhe
automaticamente uma licença de código aberto. A decisão cabe ao responsável pelo
projeto; este documento não concede permissões nem substitui orientação jurídica.

| Alternativa | Consequência geral a considerar |
|---|---|
| MIT | Licença permissiva e curta; permite redistribuição e modificações, inclusive em produtos proprietários, mediante preservação do aviso aplicável. |
| Apache-2.0 | Permissiva, com condições sobre avisos e concessão expressa de patentes; exige examinar suas disposições completas. |
| GPL-3.0 | Copyleft: a distribuição de versões derivadas envolve obrigações de disponibilização do código sob a mesma licença, conforme seus termos. |
| AGPL-3.0 | Copyleft com disposição adicional para usuários que interagem com uma versão modificada pela rede; considerar o impacto em serviços hospedados. |
| Proprietária | O titular define, em instrumento próprio, quais usos são autorizados; ausência de licença explícita não substitui um contrato de uso. |

Antes de decidir, verificar autoria e direitos sobre contribuições e materiais de
terceiros, licenças das dependências e dos recursos visuais, e compatibilidade da
distribuição pretendida. Essas condições não se resolvem automaticamente pela
escolha de uma licença para o código do projeto.

**Próximo passo:** o responsável deve selecionar uma alternativa ou solicitar
orientação especializada. Após sua decisão, registrar a licença escolhida e
verificar os avisos necessários; não criar um arquivo LICENSE antecipadamente.
